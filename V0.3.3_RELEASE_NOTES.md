# WeatherStream v0.3.3 — Map Engine 3.0

v0.3.3 focuses on geographic weather storytelling. The v0.3.1 Visual System and v0.3.2 Forecast Graphics remain intact; this release makes the dedicated Radar, Severe Weather, and automatic event channels substantially more useful by adding official NOAA/NWS map products and improving warning presentation.

## New broadcast maps

### SPC Day 1 Geographic Outlook

WeatherStream now requests the official Storm Prediction Center Day 1 categorical outlook as a transparent ArcGIS map layer and composites it over the same cached basemap used by the radar system. The graphic also displays the configured location's local Day 1 category so viewers can connect the national/regional risk area with their location.

### SPC Hazard Probabilities

A new three-panel screen presents official Day 1 SPC tornado, hail, and damaging-wind probability contours separately. Keeping the products in separate panels avoids confusing overlapping hazard colors while still making comparison possible on one TV screen.

### WPC Day 1 Weather Map

WeatherStream consumes the Weather Prediction Center National Forecast Chart map service for Day 1. The official layer includes highs/lows, fronts, rain/thunderstorms, rain, mixed precipitation, snow, and significant-weather areas such as severe thunderstorms, heavy rain/flash flooding, critical fire weather, freezing rain, and heavy snow.

### WPC 24-Hour QPF

A new precipitation map uses the official WPC Day 1 24-hour Quantitative Precipitation Forecast layer. It is especially useful in the Radar channel and automatic Flood event channel because it adds expected accumulation context beyond radar's observed/recent precipitation.

### Severe Weather Hazard Map

The new hazard board combines regional radar with:

- filled NWS warning polygons,
- event-color outlines,
- compact warning labels,
- an active-warning legend,
- and the local SPC Day 1 risk.

This creates one high-priority severe-weather map rather than requiring the viewer to mentally combine separate alert, radar, and SPC slides.

## Warning Polygon 2.0

NWS polygons previously appeared mainly as line outlines. v0.3.3 adds low-opacity event-colored fills, stronger outlines, and event labels while retaining a thin white edge for visibility on bright radar echoes. Tornado, Severe Thunderstorm, Flash Flood, and other warning/watch colors continue to use WeatherStream's existing alert color mapping.

## Background map pipeline

Official map requests are handled in `RadarManager`, not in the video-frame renderer. The map manager:

1. derives the active wide/regional Web Mercator viewport,
2. requests a transparent PNG from the appropriate NOAA ArcGIS MapServer,
3. caches the successful overlay under `/config/cache/radar/official`,
4. retains the previous/cached overlay if an upstream refresh fails,
5. exposes current/cached/unavailable state to the renderer.

This preserves the project's core rule that network I/O must never block the live render loop.

## Official services used

- NOAA/NWS Storm Prediction Center Weather Outlooks MapServer
  - Day 1 categorical outlook
  - Day 1 probabilistic tornado outlook
  - Day 1 probabilistic hail outlook
  - Day 1 probabilistic wind outlook
- NOAA/NWS Weather Prediction Center National Forecast Chart MapServer
  - Day 1 highs/lows, fronts, precipitation, and significant weather
- NOAA/NWS Weather Prediction Center QPF MapServer
  - Day 1 24-hour QPF

## Rundown integration

The RWN Radar default sequence now mixes observational and forecast mapping. The Severe Weather channel adds the geographic SPC and hazard maps. Automatic event channels receive maps relevant to the event type: Tornado gets hazard/SPC products, Flood gets WPC QPF, and Winter gets the WPC Day 1 weather map.

Existing custom order is preserved during migration. New products are inserted adjacent to related radar/SPC slides rather than replacing the user's sequence.

## Upgrade compatibility

Settings schema advances from 20 to **21**. Existing `maps.engine2` settings are used as the migration basis for `maps.engine3`; the legacy block remains readable as a compatibility fallback. Existing locations, regions, branding, encoders, Studio schedules, forecast graphics, TTS, alerts, event channels, and channel overrides remain intact.
