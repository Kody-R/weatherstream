NOSTALGIA

Local on the 8s Programming Block

A dedicated mini-program that interrupts normal RWN programming at the selected minute marks, runs every phase to completion, then returns to normal programming. Severe Weather Takeover always has priority.

CLOCKED

During a block, each phase stays on screen until its narration finishes (or its normal slide minimum time is met). If TTS is disabled or unavailable, the block still runs using normal slide timings.

Local on the 8s + Severe TTS

Optional local Piper narration. v0.2.2.1 narrates each Local on the 8s phase separately and reads only values shown on that phase's screen. Qualifying severe alerts remain the only narration outside this block.

DISABLED

The first voice download requires Internet access. Voice files and synthesized announcement cache are stored under /config/tts. Piper synthesis runs on CPU and is cached; it does not run continuously.

ZIP Codes

Every ZIP code automatically gets its own RWN Local IPTV channel. The primary ZIP additionally centers the shared RWN Radar and RWN Severe Weather channels.

RWN Network Channels

v0.2.2.1 automatically builds one HLS channel per ZIP plus dedicated Radar and Severe Weather channels. All channels are published in /playlist.m3u and /guide.xml.

MULTI-CHANNEL

Tropical Weather & Tropics Watch

Official National Hurricane Center outlooks, active systems, forecast tracks, Gulf proximity, and local NWS tropical alerts. The channel stays in the lineup but its on-demand encoder starts automatically only when configured triggers are active.

CHECKING

The forecast track describes possible center locations, not the full extent of impacts. WeatherStream never generates evacuation instructions; follow NHC, NWS, and local officials.

Realtime Video Performance

v0.2.2.1 uses a lower-cost multi-channel profile and reports whether each HLS producer is actually keeping up with wall-clock time.

PERFORMANCE

Recommended multi-channel defaults: 5 pipe FPS, 3 content FPS, 15 output FPS, superfast, 2000k, 3-second HLS segments, 10-segment window. Higher values increase CPU usage.
