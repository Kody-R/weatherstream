# WeatherStream v0.3.5 — RWN Local Observations & Climate

v0.3.5 moves WeatherStream beyond forecast-only presentation by adding a true local observational layer plus environmental and hydrologic context.

## NWS observed conditions

WeatherStream now uses the NWS points/station discovery workflow to find nearby observation stations and request their latest usable observation. When enabled, observed temperature, dew point, humidity, wind, gust, pressure, visibility, recent precipitation, description, station identity, and observation time can override the corresponding model-current fields. Any field not present in the station observation keeps the existing Open-Meteo value.

The Admin setting **Prefer NWS observations for Current Conditions** can disable that display override without disabling observation collection. This lets WeatherStream continue building an observational history while the viewer-facing Current Conditions screen remains model-driven if desired.

## Today So Far and Past 24 Hours

The history database stores station identity/source plus dew point and visibility and deduplicates repeated station timestamps. New graphics use this history for observed high/low, peak gust, temperature change, pressure trend, and temperature/pressure trend charts.

## Air Quality

v0.3.5 uses the Open-Meteo air-quality endpoint as a zero-configuration provider for U.S. AQI, PM2.5, PM10, ozone, and nitrogen dioxide. The screen identifies the source as **Open-Meteo / CAMS** and labels the values **modeled air-quality guidance**. It does not present them as an EPA/AirNow monitor observation.

## Rivers and flooding context

WeatherStream uses the modern USGS Water Data OGC `latest-continuous` and `continuous` endpoints for gage height and streamflow. Nearby gauges are ranked by distance and the primary gauge can show a recent gage-height trend. Values are marked provisional where appropriate. WeatherStream deliberately does not infer flood stage from gage height.

## Climate Context

An optional NOAA NCEI station ID enables official 1991–2020 daily temperature normals. Because NWS/ICAO observation station identifiers are not guaranteed to map directly to NCEI climate-normal stations, v0.3.5 does not guess a climate station. Without one configured, the Climate Context screen shows a clearly labeled local 30-day history summary and explicitly states that it is not an official climate normal or record.

All-time daily records are not part of v0.3.5; the official climate component is limited to normals in this release.

## Channel integration

- Local/default programming adds Today So Far, Past 24 Hours, Air Quality, and Climate Context.
- Flood event channels add Local Rivers immediately after QPF.
- Heat event channels add Today So Far, Air Quality, and Climate Context.
- Wildfire event channels add Air Quality.
- All five new products are available in WeatherStream Studio.

## Upgrade

Settings schema advances from 22 to **23**. Existing v0.3.4 icon, map, forecast, channel, Studio, encoder, and custom presentation settings are retained. The migration inserts new local-data products around related existing slides instead of replacing custom sequences.
