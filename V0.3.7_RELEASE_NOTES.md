# WeatherStream v0.3.7 — RWN Event Channel Identity

## Release goal

v0.3.7 turns RWN specialty/event channels into visibly distinct broadcast desks without forking the renderer. The same Visual System 2.0 components, maps, forecast graphics, RWN icons, and local-data products are reused with an event-specific presentation context.

## Included desks

- **Severe Weather Center** — charcoal/black, warning red, orange secondary accent, angular warning motif. Used by the standing Severe channel and Tornado event channel.
- **Flood & Hydrology Desk** — deep navy/teal/cyan with wave/grid motif. Used by Flood event channels.
- **Winter Weather Desk** — steel blue/silver/icy cyan with facet/snow motif. Used by Winter event channels.
- **Heat Weather Desk** — burnt orange/red/gold with restrained heat-wave motif. Used by Heat event channels.
- **Fire Weather Desk** — amber/brown/charcoal with smoke-band motif. Used by Wildfire/Red Flag event channels.
- **RWN Tropics Watch** — deep ocean blue/turquoise with radar-ring/ocean-grid motif. Used by the dedicated Tropics channel.

## Broadcast behavior

Event identity is intentionally channel-scoped. A normal local RWN channel does not recolor itself simply because the Story Engine classifies severe, heat, flood, or tropical weather. Dedicated channels retain their own identities consistently throughout their rundown.

The specialty lower third is also channel-aware. Examples include:

- Severe: current conditions, peak gust, next-12-hour rain chance
- Flood: 24-hour model rainfall, next-12-hour rain chance, nearby USGS gauge count
- Winter: temperature, apparent temperature, precipitation chance
- Heat: temperature, apparent temperature, humidity
- Wildfire: humidity, peak gust, AQI
- Tropical: local conditions, official-tropical-update state, local wind

No synthetic hazard level, flood stage, or warning is manufactured by the identity system. Official alerts and existing RWN data continue to determine content.

## Upgrade

Settings schema advances from 24 to **25**. Existing v0.3.6 event sequences, Studio rundowns, station themes, branding profiles, map settings, and Story Engine configuration are preserved. The new event identities are enabled by default and can be disabled globally or per desk in Admin → Event Channel Identity.
