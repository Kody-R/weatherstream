# WeatherStream v0.3.4 — RWN Icon & Motion System

v0.3.4 gives Roller Weather Network its first complete visual-symbol identity. The release replaces the original primitive weather-symbol renderer with a bundled RWN artwork library, while retaining the old procedural renderer as a compatibility fallback.

## RWN condition icon family

WeatherStream now ships separate `hero`, `standard`, and `compact` condition artwork. The resolver maps weather codes to one canonical RWN vocabulary and automatically chooses the correct day/night variant and size class.

The library includes clear day/night, mostly clear, partly cloudy, cloudy, overcast, fog, drizzle, light/moderate/heavy rain, showers, thunderstorms, severe thunderstorms, snow, heavy snow, sleet, freezing rain, wind, heat, cold, tropical, tornado, flood, lightning, and smoke artwork.

## Motion system

Selected hero and standard icons have four pre-rendered motion frames. WeatherStream advances those frames during normal content rendering for subtle cloud drift, precipitation movement, lightning, snow, wind, and tropical rotation. Compact forecast icons intentionally remain static for readability.

Animation can be disabled or slowed down in Admin without disabling the icon system.

## Broadcast symbol library

v0.3.4 also adds dedicated RWN metric symbols for temperature, humidity, dew point, wind, gusts, pressure, cloud cover, rain, UV, visibility, sunrise, and sunset.

Current Conditions and Condition Focus use the new symbols in their metric cards. The assets are available for future observation and climate screens as well.

## Alert identity

Dedicated alert artwork is bundled for tornado, severe thunderstorm, flash flood, winter storm, extreme heat, wildfire/smoke, and tropical hazards. Alert takeovers automatically choose an icon from the NWS event name.

## Asset architecture

- 207 bundled transparent PNG assets
- Central `app.iconography` resolver
- `hero`, `standard`, and `compact` condition variants
- Four-frame animation sequences for selected weather states
- Reusable metric and alert asset families
- Build/re-generation tool at `tools/generate_rwn_icons.py`
- Legacy procedural weather icons retained as a fallback

## Settings and migration

Schema 22 adds `icon_system` settings:

- enable/disable RWN icons
- enable/disable animation
- animation speed
- metric icons
- alert icons

Existing v0.3.3 installations migrate without changing channel, Studio, map, forecast, encoding, or custom sequence configuration.
