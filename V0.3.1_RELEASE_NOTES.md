# WeatherStream v0.3.1 — Visual System 2.0

v0.3.1 is a renderer-focused release built on the v0.3.0 RWN Network Studio architecture. It does not replace the existing weather, radar, Studio, event-channel, multi-region, or encoding subsystems.

## Highlights

- Resolution-independent Visual System 2.0 using a 1280×720 logical design canvas with single-pass scaling to the configured output size.
- Redesigned Current Conditions screen with a hero condition panel, dew point, cloud cover, wind/gusts, pressure, a condition story callout, and daily summary.
- Redesigned Hourly Forecast with a temperature trend line, condition icons, precipitation bars, and wind values across up to eight hours.
- New Rain Timing presentation combining precipitation probability, expected amount, peak timing, and forecast totals.
- Redesigned 7-Day Outlook using high/low trend lines, icons, rain bars, and wet-day emphasis.
- Redesigned severe-alert page with stronger severity hierarchy, affected-area panel, action text, expiration, and NWS attribution.
- Radar information strip now shows loop span, frame count, and latest image time instead of zoom/opacity/contrast operator values.
- New stable RWN Data Ribbon lower third; the classic scrolling crawl remains selectable.
- Optional forecast source/freshness badges.
- Optional condition-responsive background treatments for clear, night, rain, snow, and storm conditions.
- Presentation settings expose Visual System 2.0, footer mode, source badges, freshness labels, and condition backgrounds.

## Compatibility

- Settings schema advances from 18 to 19.
- Existing v0.3.0 custom channel sequences, themes, regions, branding profiles, Studio rundowns, encoder settings, and data behavior are preserved.
- Existing installations may switch the lower third back to `Classic scrolling crawl` in Presentation settings.
- Visual System 2.0 can be disabled, although keeping it enabled is recommended for 1080p/1440p/4K output.

## Validation

- Python source compilation completed successfully.
- 38 automated tests pass, with 3 rendering subtests.
- Core redesigned slides were rendered at both 1280×720 and 1920×1080 during release validation.
